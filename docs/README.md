## 이 문서들의 우선순위

충돌하면 `01-데이터.md`의 원칙이 가장 강하다. 이 프로젝트는 민감한 주제를 다루고,
데이터를 다루는 방식 자체가 결과물의 신뢰성이자 차별점이기 때문이다.

그다음은 `03-계획.md`의 Phase 경계다. 기능을 더 넣는 것보다 **현재 Phase를 끝내는 것**이 항상 우선한다.
